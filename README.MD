# YourTube – Video Review Web Application

## Overview

YourTube is a Flask-based web application designed to display and review video-style content. The application provides a structured interface for presenting content and user-facing information through dynamic routing and templating.

## Tech Stack

- Python
- Flask
- HTML
- CSS

## Features

- Dynamic content rendering using Flask routing
- Template-driven frontend display
- Structured content presentation
- Lightweight web application architecture

## Purpose

This project demonstrates backend web development concepts including routing, templating and server-side rendering using the Flask framework.
